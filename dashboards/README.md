# Tablero MediFlow en Power BI

Consulta el [tablero público interactivo](https://app.powerbi.com/view?r=eyJrIjoiYjU3YTBhMWItNTM5Mi00NDk4LTlkNmEtMmFmMzA2MzJjZjQ4IiwidCI6ImJhYjBiNjc5LWJkNWYtNGZlOC1iNTE2LWM2YjhiMzE3Yzc4MiIsImMiOjR9) para explorar demanda, saturación por área, tiempos de espera y flujo de pacientes.

El [proyecto PBIP](powerbi/HUN_CuellosBotella/HUN_CuellosBotella.pbip) incluye la definición del informe y del modelo semántico sin datasets ni caché. Para abrirlo en Power BI Desktop con agregados autorizados, configura el parámetro `RutaDatos` con la ruta absoluta a la carpeta de esos archivos y pulsa **Actualizar**. El jurado puede consultar el tablero público sin este paso.
