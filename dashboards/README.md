# dashboards/

## powerbi/

Dashboard de Power BI (responsable: Juan).

- **Solo se versionan plantillas `.pbit`** (estructura, medidas y visuales, sin datos).
- Los `.pbix` contienen datos y están bloqueados por el `.gitignore`.
- Para exportar: *Archivo → Exportar → Plantilla de Power BI*.
- El dashboard debe leer los datos desde `data/processed/`.
