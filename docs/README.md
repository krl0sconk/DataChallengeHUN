# docs/

Documentación del proyecto: decisiones técnicas, diccionario de datos, metodología del modelo,
guías de uso de la aplicación y del dashboard, y material de las entregas.

- [decisiones.md](decisiones.md): bitácora de decisiones técnicas.
- [diccionario_datos.md](diccionario_datos.md): tablas de la base, diferencias con las bases del reto y consecuencias.
- [objetivo_prediccion.md](objetivo_prediccion.md): qué predice el modelo y cómo se evalúa.
- [protocolo_factores_externos.md](protocolo_factores_externos.md): cómo se decide si un factor externo aporta.
- [guia_sesion_bd.md](guia_sesion_bd.md): paso a paso para conectarse a la base y extraer los agregados.
- `resultados/`: reportes generados por el código (solo métricas agregadas).
- [datos_externos.md](datos_externos.md): fuentes y variables de los datos externos.
