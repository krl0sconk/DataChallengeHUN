# notebooks/

Notebooks de trabajo, organizados por etapa:

- `01_exploracion/`: análisis exploratorio (EDA).
- `02_preparacion/`: limpieza, uniones y análisis de cuellos de botella.
- `03_modelado/`: entrenamiento y evaluación de modelos.

Nombre: `<NN>_<etapa>_<iniciales>_<tema>.ipynb`, por ejemplo `01_exploracion_kd_llegadas.ipynb`.

Los outputs se eliminan al hacer commit (`nbstripout`) porque pueden contener datos de pacientes.
El código reutilizable debe pasar a `src/hun/`.
