# app/

Aplicación web para mostrar las predicciones de flujo de pacientes al personal del hospital.

**Líder:** Daniel. **Framework:** por definir (registrar la elección en `docs/decisiones.md`).

- Consumir las predicciones generadas por el paquete `hun`.
- No incluir datos de pacientes en el código ni en archivos estáticos.
